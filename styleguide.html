Style guide

This page is a rough and limited style guide for the deranged brand. The brand is designed flexibly and with a content-first mindset, and should be reusable across all platforms and mediums.

Good design sources you can uncritically lean on:

  • Visual design rules you can safely follow every time by Anthony Hobday
  • The Gestalt Principles

Content first

Before starting to design a page, figure out the content. Design should always be in service of an actual message. Do not adhere to established norms in the design if they make it harder to punch through with your message.

Make sure that each page quickly makes the point, and visitors can quickly tell if we are appealing to them or not.

The front page starts with a full-page element saying "So nice to meet you" to subvert expectations of visitors who have not yet been segmented/are not linked into more specific content. It should not be emulated on other pages, as repeating the pattern weakens it. And on other pages we know what they are looking for. TL;DR: the front-page is exceptional, don't copy patterns from it. Other pages need to get to the point quickly. That's hard for the frontpage, because deranged is hard to pin down. What is the point?? That's why it subverts expectations instead.

On segment or product pages, write so that visitors can see that you:

  • Understand what problems they might have
  • That we can help solve them with expertise

For blog posts and explainers, share useful information. The goal is to look like the experts we are, not to increase sales.

Never write marketing-y bullshit. Write naturally and confidently. Kill your darlings, delete filler words.

It is okay to write with edge and humor, to make some personality shine through. We aren't every other brand.

Minimal elements

Use minimal changes for the effects you want. You have your content, now make it look good.

First, use spacing and position to group the right elements together and tell your story. (Consult the gestalt principles.)

Only if spacing is not enough, you can add a border.

Only if a border is not eonugh, you can change a background color.

Don't overdo it! Lots of color changes make the design look messy.

Alternate section backgrounds to keep it fresh

Alternate between sections with light background and dark. It keeps the design interesting. Use .section--dark for dark styled sections.

Avoid boring section transitions

Try to avoid long straight lines when transitioning from one section to another.

Instead, try to break up the shape of the transition by having elements overlap the harsh line, or replace the straight line with a shape, e.g. a downward facing chevron.

You can use an element with .section__exit-chevron to create a chevron into a new section color.

UTF8 icons

Instead of using an icon pack, see if there is an UTF-8 character that will work for your purposes. Use UTF8 characters as filler and stylistic input. There are loads of fun little arrows and stuff.

Brand colors

  • #2c3e50 Dark blue (primary brand color) Also primary text color.
  • #375068 Active state brand color (e.g. hovered buttons)
  • #1b2b3a Darkened brand color (e.g. footer, dark fade target of gradients)
  • #ecf0f1 Off-white background-color.
  • #eaf1f7 Off-white text-color for dark backgrounds.
  • #0e3661 Link on light background
  • #d3e6f8 Link on dark background

Fonts

The primary brand font is Source Sans Pro.

For serif text, we use Libre Baskerville. (We could consider switching to Source Serif Pro for a more unified look.)

For code, we use Source Code Pro.

Body text

Use the default font in size 18px as the default font-size. This should already be the default anyway.

For some long text sections you may want a more book-y vibe, in which case you can use the class .font-serif to get a Serif font. Use serif fonts very sparingly and only if you really need that different feeling.

Headings

Headings are never normal weight. Headings are always normally cased, never UPPERCASED.

Display headings are used to catch users' attention, and are large text on the site. Per default they should use font-weight: 300 (light):

Normal headings, not for display purposes, are extrabold, font-weight: 900; and much closer in side to normal text:

Links

This is a little bad... default links are styled to be on dark background, and you can use .link--dark for links on light background. Messy, we should probably fix that.

Use link-looking links for linking to other content, on the page or externally.

Use buttons only for exceptional CTAs iff it is inviting users to start or perform an action. That is, a button can be a link only if it links directly to e.g. a form where the user can perform an action. Otherwise it must be a textual link.
